# Orientações para Claude Code

Use `AGENTS.md` como instrução principal do projeto: leia-o integralmente antes de alterar código, documentação ou infraestrutura. A fonte de verdade de produto é `docs/00_PRODUCT_VISION.md` e `docs/02_PRD.md`.
